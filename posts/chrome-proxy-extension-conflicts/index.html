系统代理开着，Chrome 却没走？检查代理扩展

小六2026-10-08— 次阅读
客户端教程

Windows 的代理开着，其他软件也正常，Chrome 却走了另一条路。先检查浏览器是不是还有自己的代理扩展。

同一台电脑，可能有好几处在决定怎么走

Chrome 的代理设置可能受系统、扩展、自动脚本或组织策略影响。扩展里选择“直连”“跟随系统”或某个固定代理，含义都不同。

别只看扩展图标是亮的还是暗的。先记下当前模式和地址，确认它到底要求浏览器走哪里。

临时停用相关扩展做对照

进入 Chrome 的扩展管理页面，找到负责代理切换的扩展。保持桌面客户端、节点和网络不变，先临时停用它，再重新访问同一个目标。

不用立刻卸载扩展，也不用清空全部浏览记录。如果结果改变，就继续核对扩展配置；这只是说明它与差异有关，不代表节点出了问题。

只有部分网站不同，查排除规则和脚本

有些设置会按网址选择直连或代理，HTTP 和 HTTPS 也可能采用不同安排。因此，一个网站正常不能证明全部请求都用了同一个入口。

在客户端记录中找到目标请求，检查实际规则和出口，比仅看浏览器主页有没有打开更准确。

管理中的浏览器，先看配置来源

如果设置页提示由组织管理，可能存在工作环境要求，不要擅自移除策略。把具体网址、扩展模式和报错整理给管理员。

排查结束后，让自己使用的设置来源保持明确。避免多个工具同时改代理，下一次出现问题时才能知道从哪里查起。

网页麦克风用不了？Chrome 和 Windows 11 这样检查

小六2026-11-26— 次阅读
网络排障

网页提示麦克风不能用，或者你说话对方听不到，可以按“电脑能否录音、系统是否放行、网站选了哪个麦克风”的顺序检查。Chrome 里点过允许，只解决了其中一层权限。

这篇以 Windows 11 上的桌面版 Chrome 为例。小六建议每改一处就试一次，顺手记下结果。这样发现声音恢复时，才知道是哪一步起了作用。

先在电脑上录一句话

先看耳机或麦克风上的静音键，再检查网页里的麦克风按钮。接着做一次本机测试，把“电脑没收到声音”和“网页没有传出声音”分开。

  1. 打开 Windows“设置 → 系统 → 声音”。
  2. 在“输入”里选中正在使用的麦克风，打开它的属性。
  3. 找到麦克风测试，开始测试后说一句话，再停止并播放录音；声音太小时检查输入音量。

具体入口可参考微软的设置和测试麦克风说明。不同系统版本的按钮文字可能略有区别，以“输入”和“麦克风测试”为线索找就行。

如果连测试录音也没有声音，先继续查设备连接、输入选择和下面的系统权限。如果录音正常，记住刚才选中的设备名称，后面去 Chrome 里对照。这个结果说明本次本机测试能收音，还不能证明网页通话已经正常。

Windows 权限里，别漏掉桌面应用

打开“设置 → 隐私和安全性 → 麦克风”，检查“麦克风访问权限”和“允许应用访问你的麦克风”。对于桌面浏览器，还要查看“允许桌面应用访问你的麦克风”。微软的麦克风权限指南分别说明了这些设置。

列表里没找到 Chrome 的独立开关，不一定是安装出了问题。Windows 对桌面应用的控制方式与商店应用不同，不能在这里逐个切换桌面应用；相关范围见微软的麦克风隐私说明。

打开桌面应用访问权限后，具体哪个网站可以使用麦克风，还需要在浏览器里核对。

Chrome 要核对网站和输入设备

进入 Chrome“设置 → 隐私和安全 → 网站设置 → 麦克风”。先检查当前网站是否在禁止列表中，需要使用时再把这个网站改为允许；随后在麦克风选择框里，核对是否选中了刚才测试正常的设备。操作依据是 Google 的摄像头与麦克风帮助。

比如你戴着 USB 耳机准备开会，就对照耳机的设备名检查，而不是看到“麦克风”三个字就跳过。若网页自己的音频设置也提供输入选择，再核对一次，随后重新进入语音功能试说一句。

工作或学校管理的 Chrome 可能限制权限修改。如果选项显示由管理员控制，把网站地址和提示交给管理员处理。

权限允许了，仍然要看网页里的状态

“允许使用麦克风”不等于“正在发送声音”。Google 的排查说明也提醒用户检查耳机静音和网站里的静音状态。

可以做一个短对照：保持同一台电脑、同一个麦克风和同一网络，只重新进入出问题的网页语音功能。如果它提供输入音量提示，观察说话时是否有反应；没有这类提示，就记录它给出的报错文字。

例如，“未获得麦克风权限”“没有可用输入设备”“正在连接”是不同线索。求助时把原话写下来，比一句“语音坏了”更容易让人判断下一步。

能收音但一直连接中，再查网络

假如本机录音正常，网页也能检测到输入，却迟迟建不起通话，排查方向可以转向连接过程。不过，这些现象只是线索，不能直接断定机场节点有问题。

遇到“网页能打开，语音却连接不上”，可以继续看语音和游戏连接的 UDP 检查方法。如果连文字聊天也反复重连，则更适合参考网页聊天一直重连的排查方法。两种情况不要混着处理。

需要向客服描述时，可以照这个格式填写：本机测试是否有声音、Windows 权限是否开启、Chrome 选中的设备名、网页提示原文。用自己的实际结果替换，比反复切换所有设置更方便继续查。
